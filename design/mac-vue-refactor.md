# macOS 原生界面对齐 Vue

2026-09-17：按用户要求，Mac 的视觉依据改为当前 Vue 控制台 `design/web-ui-standard.md` 与 `oci-start-web/src/styles/tokens.css`。仍使用 SwiftUI / AppKit，支持 macOS 11；没有将业务页面替换成网页。

## 已实现

- 全高深色侧栏为 220pt，收起后保留 76pt 图标导航；品牌置顶、用户及服务来源置底。56pt 顶栏只覆盖内容区，包含菜单搜索和已有账户、消息、语言、外观、刷新与 Mac 更新入口。
- `AppTheme` 区分侧栏、页面、卡片、输入框、悬停与文本颜色。浅色普通文字为纯黑；深色为近黑表面与可读白字，主色为 `#1b8a6a`。首次使用跟随系统，已有外观偏好继续读取。
- 公共按钮、表单、原生输入框、下拉、表格、分页、空态与弹窗统一字级：正文 14、辅助 13、徽标 12、模块标题 16、弹窗标题 18pt。图表标注和终端字号保留各自用途。
- `PageScaffold` 的列表模式使用 24pt 页边距与 18pt 圆角单卡片，配置/监控/日志等使用独立工作区；不重复显示大页面标题。租户子页工具栏继续显示操作对象与区域。
- 租户、实例、开机的搜索/筛选和操作进入同一工具区，宽度不足时分两行。表格保留原有固定表头、纵向滚动与必要的横向滚动；公共分页在容器小于 800pt 时分两行，避免多页按钮挤压总数和跳转控件。
- 登录页使用 Vue 的左右平铺布局、紧凑表单和绿色操作。点阵世界地图用 AppKit 本地绘制，区域目录来源沿用 Vue 的公开静态目录；示意连线不表示连接状态。

## 保留的能力

本地/远程部署选择、服务器地址、Java 后端启动、认证与注册、找回密码、验证码/MFA、现有 OAuth、云厂商切换、通知、资产、Mac 安装包更新与原生菜单快捷键均继续使用原实现。REST/WebSocket 服务、ViewModel、数据模型和危险操作确认没有因外观重构而替换。

## 范围与验证

这是现有 Mac 原生界面的视觉和布局迁移。Mac 原有网络质量配置、区域面板和未实现的多云占位保持各自业务范围，不能据此认为已完整迁入 Vue 所有新增业务能力。

- macOS 11.7 / Xcode 13.2.1 / Swift 5.5.2 下，`OciStart` Debug 构建通过，编译错误与警告均为 0；`git diff --check -- oci-start-mac` 通过。
- 完成 16 张原生窗口截图检查：租户浅/深色及 960pt 窄窗口、安全管理、系统监控、收起侧栏的实例页、首次部署选择、登录、MFA、英文注册、浅深色密码重置，以及三种长表单滚动到底部的状态。已修复操作按钮折行、窄窗口分页范围文字受挤压的问题；最终分页使用 7 页测试数据复查。
- 截图程序使用独立可执行文件、隔离偏好与 URLProtocol 拦截响应。租户列表使用本地示例数据，其余业务请求使用受控离线错误；登录分支由本地表单状态呈现。没有启动嵌入后端，也没有操作真实云资源。
- 本轮改动与开始时的工作区快照比较，共 70 个 Swift 界面文件变化，Core、Service、ViewModel 与 Models 没有本轮新增变化。真实认证成功、OAuth 回调、本地后端启动、云资源读写与安装包仍需实际部署验收。
