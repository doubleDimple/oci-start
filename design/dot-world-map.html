点阵世界地图

Canvas 2D 绘制，无第三方依赖，按经纬度点亮标记。放在页面任意容器里即可。

浅色主题

同一个组件，换一组颜色。

接入方式

<div id="world" style="width:100%"></div>

<script src="dot-world-map.js"></script>
<script>
  var map = DotWorldMap(document.getElementById('world'), {
    theme: 'dark',
    points: [
      { id: 1, lat: 31.2304, lng: 121.4737, name: '上海' },
      { id: 2, lat: 1.3521,  lng: 103.8198, name: '新加坡' }
    ],
    onSelect: function (p) { console.log('点击了', p.name); }
  });

  // 后端拉数据
  fetch('/api/nodes')
    .then(function (r) { return r.json(); })
    .then(function (list) { map.setPoints(list); });

  // WebSocket 推来一个新节点，实时点亮
  ws.onmessage = function (e) { map.add(JSON.parse(e.data)); };
</script>

API

方法 / 选项说明
setPoints(list)整体替换数据，字段兼容 lat/latitude、lng/lon/longitude、name/title
add(point)追加一个点并触发点亮动画，返回内部对象
remove(id)按 id 移除
clear()清空
focus(id)把某个点设为高亮态
set(opts)运行时改选项，如 { arcs:false }
destroy()停止动画并解绑事件
onSelect(p)点击标记的回调
arcs / labels / pulse连线、标签、脉冲开关，默认全开
dotStep点阵密度（像素间距），默认 5，调大更稀疏、更省性能
