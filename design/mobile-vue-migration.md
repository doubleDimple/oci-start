# 移动端 Vue 控制台

登录后的移动端页面复用 `oci-start-web` 的业务组件、接口、会话和主题。宽度不超过 760px 时使用手机导航和列表卡片；更宽的窗口继续使用桌面布局。调整窗口大小不会重新挂载整张业务页面。

手机租户首页采用两行摘要，点击整行或箭头进入详细信息；`detail` 查询参数保留原搜索条件和分页，完整费用、状态与业务操作继续使用原租户列表数据。

## 入口与功能

旧 `/m` 收藏地址保留，路由别名定义在 `src/router/mobile.ts`。页面刷新由后端 `VueSpaFilter` 提供 Vue 入口；仅明确列出的 GET/HEAD 页面进入 SPA，`/m/api/**`、登录提交及写入请求保持原处理方式。`/login`、`/m/login` 和 `/forbidden` 为公开 Vue 页面。

| 旧入口 | Vue 功能 |
| --- | --- |
| `/m`、`/m/tenants` | 租户管理 |
| `/m/boot` | 开机任务 |
| `/m/instances` | 资源监控、实时指标、Ping、探针与质量检测 |
| `/m/speedtest` | 区域测速 |
| `/m/monitor` | 系统资源监控 |
| `/m/arm-regions` | 区域管理 |
| `/m/settings` | 安全管理 |
| `/m/notify-settings` | 通知管理 |
| `/m/ai` | Telegram AI 模型配置 |
| `/m/cloudflare` | Cloudflare 管理 |
| `/m/memo`、`/m/mfa` | 笔记与 MFA 备份 |
| `/m/traffic`、`/m/cost` | 流量与费用查询 |
| `/m/region-sub`、`/m/audit-log` | 区域订阅与审计日志 |
| `/m/user-mgr` | 租户用户、安全策略、通知邮箱等原功能 |
| `/m/disk-info`、`/m/security-rules`、`/m/storage-instances` | 磁盘、安全规则、MySQL 实例 |
| `/m/vnic/manage` | 实例网络管理 |

另外提供 `/m/oci-instances` 访问 OCI 实例管理；资源监控卡片可按租户进入该页面执行云实例操作。旧 `/m/instances` 主要展示资源指标，不能仅替换为没有探针功能的 OCI 实例表。

租户子页面继续使用 `tenantId` 参数，并从后端验证其实际记录。ID 按字符串保留，`tenantName` 等查询参数不作为身份依据。VNIC 的 `instanceId` 是 OCI OCID，与数据库数字 ID 不混用。

按用户要求，移动端移除系统救援。旧 `/m/sysHelp` 重定向到实例列表；手机访问桌面救援地址也会返回实例列表。旧移动端脚本的救援按钮已移除。

## 登录与部署

登录继续沿用服务端的 RSA、MFA、验证码及 OAuth 流程。补齐 `/m/login` 与 `/login` 的同一登录处理器映射和匿名访问规则，避免旧移动端登录跳转落入不存在的地址。

生产部署仍只需要原来的 Java 服务端口。Vue 构建产物写入 `oci-server/src/main/resources/static` 后随 JAR 打包，不需要另外部署移动站点或开放 Vite 端口。

本次包含 Java 路由变更；本地开发需重新编译并重启后端才能使用新服务端路由。仅 Vite 热更新不会更新运行中的 Java 类。

## 验证

- `pnpm --dir oci-start-web run build`：类型检查与生产构建通过。
- `MobileVueRoutingTest`：58 个隔离案例通过，覆盖页面登录保护、已登录转发、API/非 GET 放行、无前端资源时的鉴权及救援入口重定向；不启动真实应用或数据库。
- 浏览器以隔离的测试响应验证 22 个移动入口；在 320、375、390、430、760、761 和 1440px 下检查布局，无页面横向溢出，跨断点切换不重新挂载业务页面。
- 检查抽屉键盘焦点、底部导航与刷新、深浅主题及中英文切换；在 320px 下检查磁盘、安全规则和 MySQL 卡片，并验证安全规则上一页/下一页的数据切换。没有执行真实云资源操作。

真实账号下的云端启停、探针安装和其他写入功能复用原逻辑，本次未对真实资源执行这些操作。

## iOS 外观与所有业务记录列表

`mobile-ios.scss` 统一手机导航、分组表面、细分隔线、标签栏、返回按钮和底部表单浮层；支持深色模式、英文及安全区域，桌面继续使用原布局。移动外观设置采用带勾选状态的分组行，内容配色同时作用于手机功能菜单。

除租户外，实例、开机任务、区域/订阅、DNS、VNIC、VPN、AI 模型、对象存储、邮件、笔记、MFA、审计、网络质量、费用/流量明细、迁移结果和资源弹窗均采用摘要→详情。共享 `MobileRecordList` / `MobileRecordCard` 保留原字段、操作和禁用条件；设置选项、图表和实时日志流继续按自身用途展示。

详情选择使用 `mobileRecord` 查询参数，弹窗子记录用 `mobileRecordParents` 保存父记录；同页的并列列表不会互相当成父子。选择必须匹配该列表实际加载的记录，不用显示名称作为资源身份。可恢复的服务端上下文随查询参数保留；临时上传文件、迁移结果与手动查询结果不会因刷新自动重放操作，记录不存在时提示返回列表。

### 本轮界面验收

- `pnpm --dir oci-start-web run build`：Vue 类型检查及生产构建通过。
- `node --test oci-start-web/tests/mobile-record-navigation.test.mjs`：10 项隔离测试覆盖并列列表、父子详情、历史返回、路径/筛选隔离，以及保留 DOM 的上传弹窗关闭。
- 20 个模拟数据浏览器场景通过，覆盖摘要/完整字段、返回、刷新、分页及开机任务嵌套详情；浏览器无页面错误。头像菜单另在 320/390/760px、中英文及深浅主题下验证宽度、位置、图标和设置入口。
- OCI 区域管理在手机上默认收起地图；显示/隐藏按钮及区域定位仍可展开地图，刷新恢复默认收起。桌面首次进入继续展示地图。
- 登录页现由 `src/views/auth/LoginView.vue` 实现，包含登录、首次注册、重置密码、消息/MFA、OAuth 与 Turnstile。小屏继续采用 iOS 样式和底部重置密码浮层，兼容旧 `mob-theme` 偏好与登录错误跳转提示；桌面保留点阵地图。

登录页面也由 Vite 构建与热更新。公开初始化接口 `/api/auth/bootstrap` 提供显示配置和会话 RSA 公钥，私钥只保存在服务端会话。首次升级此版本须同时更新后端及 Vue 资源；详情见 [FreeMarker 移除说明](vue-only-migration.md)。
