# Web Vue UI 标准（视觉真源）

**后续所有 Web 页面都必须按本文设计和实现。**

**2026-09-13 最新字色要求：Vue 控制台浅色模式的普通文字全部使用纯黑 `#000000`（正文、表头、表单标签、说明、页脚与占位提示）；`--text-primary/secondary/muted` 统一为纯黑，层级由字号、字重和间距区分。本要求覆盖下文旧 Apple 灰字分级。深色保持清晰白字，深色侧栏、按钮反白、危险/成功等语义色保持可读；独立登录与地图原型配色按专项。**

## 骨架（全站同一套壳）

```
┌──────────┬─────────────────────────────────────────────┐
│ 深色侧栏  │  顶栏：搜索（左） · 通知/日期 · 用户（右）     │
│ 通顶     │─────────────────────────────────────────────│
│ Logo     │  内容：业务统计或列表卡片，直接开始            │
│ 导航     │  卡内：搜索/筛选 · 必要操作 + 主按钮            │
│ 氛围区   │  白卡片网格，间距 16–20px                    │
│ 用户卡片 │                                             │
└──────────┴─────────────────────────────────────────────┘
```

1. **侧栏通顶**（不是 easy-dev 那种顶栏先横贯再侧栏）。宽约 **220px**，折叠约 64px。
2. **内容区浅底**，自己带一条矮顶栏（搜索 + 工具 + 头像），不压在侧栏上面。
3. **内容直接开始**（2026-09-13 用户锁定）：已完成页面和后续所有迁移页面都不再重复展示页面大标题、欢迎语或装饰说明。必要操作并入现有卡片工具栏，最多 **一个** 实心主按钮（森林绿）；页内业务模块标题保留。
4. **内容全部进白卡片**，不要通栏裸表、不要 iframe 感的灰块堆砌。
5. **Web 铺满浏览器视口**：侧栏贴左、主区贴右，无外壳 padding、无整窗外圆角。图上的灰衬底 + 大圆角是 Figma 展示框，只给 Mac 系统窗口用，不要抄进浏览器。

侧栏结构（对 oci-start 菜单，不改分组顺序）：

- 顶：Logo 叶标 + 产品名 + 一句副文案
- 中：导航。当前项 = **绿色圆角胶囊**（白字）；其它项 = 浅色图标 + 灰白字
- 下：可选氛围图 + 一句短文案（可用渐变代替版权图）
- 底：当前用户（头像 + 名 + 角色）

## 字体（Apple Store）

```
-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display",
"PingFang SC", "Hiragino Sans GB", "Noto Sans SC", "Microsoft YaHei",
"Helvetica Neue", Helvetica, Arial, sans-serif
```

- 禁止 Avenir Next / Inter / Roboto 打头（中英混排发糊）。
- **字号按当前 Vue OCI 实例列表统一（2026-09-13 用户指定）**：正文、表格主文本/表头、按钮、输入框与表单标签 **14px**；说明、副行与页脚 **13px**；紧凑徽标 **12px**；业务模块标题 **16px**；弹窗标题 **18px**。正文行高仍约 1.47，标题字重 **600**。统计大数字保持各图表既有层级。
- 统一使用 `--font-size-body/secondary/caption/section/dialog-title`，值只在 `tokens.css` 定义。不得为了紧凑布局再把主文本缩至 11–13px，`size="small"` 只控制组件高度/间距，不降低文字字号；手机断点也沿用同一字级。
- 覆盖所有已完成及新增迁移页面、共享导航与相关弹层；已认可的独立登录原型和 Canvas 地图绘制尺寸遵循各自专项，不受控制台字号规则改写。
- `font-synthesis: none`；`-webkit-font-smoothing: antialiased`；`-moz-osx-font-smoothing: grayscale`。
- 表格/表单/按钮必须继承 `--sans` 和 `--text-*`，不要 Element Plus 默认灰字。

## 尺寸与形状

| 元素 | 规则 |
|---|---|
| 卡片圆角 | **16–20px**（大圆角，不是 6px） |
| 按钮 / 搜索 / 导航胶囊 | **999px 或 12px**，主按钮偏胶囊 |
| 侧栏宽 | 220px；折叠 64px |
| 内容内边距 | 24–32px |
| 卡片间距 | 16–20px |
| 顶栏高 | 约 56px |
| 内容区页标题 | 不重复展示页面名称；操作就近并入卡片工具栏 |
| 表行高 | 约 48–52px |
| 阴影 | 卡片轻阴影，禁止重投影、禁止毛玻璃乱飞 |
| KPI 图标 | 40px 圆底 + 单色图标，不要彩色胶囊标签当类型 |

## 组件怎么用这张图

| 场景 | 对图上的哪一块 |
|---|---|
| 仪表盘 | 业务 KPI 直接置顶，下方监控卡片网格；不加欢迎行或重复页标题。数据用现有 `/boot/dashboard-stats` 等，不编造 |

## 区域地图专项

用户最终效果参考 `design/dot-world-map.html`（2026-09-13），随后明确去掉立体地球、只保留平铺并增加原型动态连线。使用 Canvas 2D 点阵地图，深/浅配色、点阵密度、发光标记、脉冲、细弧线和流动光点按稿实现；连线默认开启且可独立关闭。这是图内可视化风格，不改变控制台全站字体/布局。真实 ARM 与我的区域同时展示，交集区分；连线仅为用户要求的视觉动效，不引入示例数据或拓扑/流量等业务含义。地图全宽展示、列表保持轻表头与现有业务操作；所有控制和提示国际化。

## 登录页专项

2026-09-13 用户最新指定 `design/oci-start-login.html`，覆盖此前大叶形 Logo 登录方案。左侧小品牌、文案和平铺点阵地图，右侧紧凑登录表单；地图添加动态弧线与流动光点。登录页局部 tokens 按稿提供深浅两套色值，保留系统字体与绿色主操作。现有服务端登录、二验、注册、找回密码、OAuth 条件与跨端 RSA 抓取接口保持；原型仅用作视觉与动效参考，不引入模拟请求或虚假状态。

用户进一步要求完全按原型的布局和样式实现，登录注册逻辑保持此前实现。主 CSS 直接使用原型原文，恢复同款 DOM 层级、默认行高、字体列表、表单总宽/内边距和断点，不自行优化尺寸或添加另一套布局。原型缺少的真实业务流程通过局部兼容样式接入，不改主表单规则。

## 国际化

所有 Vue 迁移页面同步补齐中英文，不只处理菜单。工具栏、表头、菜单、弹层、表单、状态/空态、校验/确认/反馈、placeholder、title、aria 文案都进语言包。动态标题、选项和本地持久错误在渲染或 computed 中翻译，日期/时间/数字随语言更新。按枚举 code 翻译展示值，保留真实用户数据/服务端文本与请求契约。英文布局允许合理换行、表格横向滚动。

## 自定义内容配色（2026-09-13 用户补充）

- 顶部调色作用于整套内容主题：页面、卡片、搜索/输入、表头、文字、边框、悬停、禁用、弹窗/下拉、空态插图和图表。卡片等表面从内容底色推导相近色，仍保持可分辨的层次；色值与混色规则集中于 `tokens.css`。
- 自定义底色明暗决定内容文字与控件的明暗配套；浅色普通文字继续纯黑，深色用可读白字。侧栏独立，原浅/深/跟随系统模式以及各模式保存的配色不混为一项。恢复默认同时还原整个内容调色板。
- Element Plus 的所有表面、边框及语义浅色阶都映射到共享 tokens，不能在暗色页面残留默认白色填充。图表同步监听自定义配色变化，使用已解析的实际颜色刷新文字、网格、图例和提示框，并保留用户的图例选择。
- 费用查询工具栏、分类汇总、趋势与明细放在同一卡片中并对齐内边距；列头和数据采用一致的对齐方式与宽度，金额单行且使用等宽数字，长资源/服务名称省略并保留完整提示，窄屏允许横向滚动。


## 页级返回与数据空态（2026-09-13 用户补充）

- 页级返回统一复用 `PageBackButton.vue`，使用左箭头 +「返回 / Back」、36px 高描边胶囊、14px 系统字体与普通字色；放在顶部工具栏的第一个位置，不再散落到右侧或空态中央。不要用页面局部 CSS 覆盖它的尺寸。原页面返回目的地、站内历史兜底和提交禁用规则保持。
- 流量查询的汇总、占比、柱状趋势、实例明细区域在初次进入即显示；加载/错误/未查询/无记录都保留模块。未知数据用「—」和空态，不能编造0流量、100%剩余额度或虚拟实例。真实阈值读取完成后独立显示，空图不显示虚构数值刻度。
- 流量趋势使用分组柱状图；语言/主题变化或滚离再滚回时保留用户的图例选择。
- 审计日志使用独立 Vue 页面承载筛选、表格与分页，从租户操作栏跳转；查询路径、字段及游标沿原接口，清空筛选不等于删除审计事件。

## 移动端 iOS 风格（2026-09-16 用户补充）

- 不超过 760px 时采用 iOS 分组列表：系统字体、17px 居中导航标题、16px 摘要标题、13/12px 辅助文字；继续使用项目绿色和主题 tokens，浅色普通文字保持纯黑。
- 顶部导航与底部五个标签使用细分隔线，选中标签用绿色图标与文字。功能抽屉采用同主题分组表面，避免手机内再嵌入桌面侧栏外观。
- 业务记录先显示两行摘要和右箭头，点整行进入完整字段与操作；租户、实例、任务、资源、日志记录及弹窗子记录复用同一模式。筛选选项、表单字段、图表和实时日志流不作为业务记录折叠。
- 手机返回按钮复用 PageBackButton，按本次要求覆写为绿色左尖括号与文字、44px 点击高度；桌面保留原36px描边胶囊。
- 编辑表单使用底部浮层，删除等确认使用居中提示框；输入字号不低于16px以避免 iOS 聚焦时自动缩放，兼容安全区域和深色/自定义内容主题。不绘制假的系统状态栏。
- 移动专用外观集中在 `src/styles/mobile-ios.scss`，只在手机断点生效；桌面组件、接口及权限/确认逻辑继续复用。
